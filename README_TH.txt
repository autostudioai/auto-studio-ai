AUTO STUDIO AI — WEBSITE PACKAGE

ไฟล์นี้เป็นเว็บไซต์สำหรับ Auto Studio AI เพื่อใช้เป็น Official Website
และเตรียมใส่ใน TikTok for Developers

ก่อนนำขึ้นออนไลน์:
1) เปิด contact.html
2) เปลี่ยน REPLACE-WITH-YOUR-REAL-SUPPORT-EMAIL@example.com เป็นอีเมลติดต่อจริง
3) ห้ามใช้ URL สมมติในการกรอก TikTok Developer

โครงสร้าง:
- index.html       หน้าแรก
- terms.html       Terms of Service
- privacy.html     Privacy Policy
- contact.html     Contact
- style.css        ดีไซน์
- assets/          โลโก้

หลังขึ้นออนไลน์แล้ว:
- Web/Desktop URL = URL หน้าแรก
- Terms URL = URL/terms.html
- Privacy URL = URL/privacy.html

TikTok ระบุว่าเว็บไซต์ต้องเป็นเว็บไซต์จริงที่พัฒนาแล้ว ไม่ใช่หน้า landing/login อย่างเดียว
และต้องมี Terms + Privacy ที่มองเห็นได้และใช้งานได้ รวมถึงต้อง Verify URL ownership ก่อนส่ง Review
